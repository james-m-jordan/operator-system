# LESSONS

Reusable behavior supported by evidence for `{{ORG_NAME}}`. Look up relevant
rules on demand; keep within the configured compact-memory budget.

- Record a lesson only when new evidence supports a reusable change.
- Format: `- YYYY-MM-DD | rule | evidence: reference | hits: N`.
- Exact rules are confirmed once per evidence reference. Similar wording is a
  conflict candidate, never automatic confirmation. Preserve the first-seen date.
- Hit counts do not prove independent corroboration or authorize promotion.
- Review benefit, scope, and counterexamples before promoting or importing rules.
- Retire contradicted or superseded rules; preserve rare but valid ones.
- A no-change run is healthy and requires no lesson.
